06 / READ THE FINE PRINT

A scenario, not a migration recommendation.

Cloud estimates use on-demand VM and Standard object storage list rates with no commitment discounts. Workload storage is decimal TB, converted to billable GiB. AWS S3 uses its 50 TiB and 450 TiB price tiers for each region. Storage API requests, cross-region replication traffic, managed databases, VM disks, egress, taxes, and financing are outside the baseline; enter a monthly allowance above where relevant. Rack fee is a planning allowance for space, with metered power and cooling modeled separately. Obtain a colocator quote to avoid double counting bundled power. Hardware is repurchased at the selected refresh cycle with no salvage value.

50 physical servers are a conservative one-to-one assumption for 50 VMs; CPU performance, availability, and storage throughput are not benchmarked here. The result is a financial scenario, not a migration recommendation.
